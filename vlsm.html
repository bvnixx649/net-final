VLSM

โจทย์จะให้ IP มาหนึ่งก้อน พร้อมรายชื่อแผนกที่ต้องใช้เครื่องคนละจำนวน งานของเราคือแบ่งก้อนนั้นให้ทุกแผนกได้วงของตัวเองแบบพอดีขนาดและไม่ทับกัน แล้วตอบ [[netaddr]], [[prefix]], [[range]] และ [[bcast]] ของแต่ละวง

IP คือเลขฐานสอง 32 หลักIPv4 = 32 bits = 4 octets

เลขอย่าง 192.168.1.10 ที่เราเห็น จริงๆ คือ [[bit|บิต]] 32 ตัวที่ถูกตัดเป็น 4 ชุด ชุดละ 8 บิต เรียกว่า [[octet]] แล้วแปลงแต่ละชุดเป็นเลขฐานสิบให้คนอ่านง่าย

ใน octet หนึ่ง บิตแต่ละตำแหน่งมีค่าประจำตัว จากซ้ายไปขวาคือ 128, 64, 32, 16, 8, 4, 2, 1 บิตไหนเป็น 1 ก็เอาค่าของตำแหน่งนั้นมาบวกกัน ผลรวมคือเลขฐานสิบของ octet นั้น เพราะฉะนั้น octet หนึ่งมีค่าได้ตั้งแต่ 0 (ปิดหมด) ถึง 255 (เปิดหมด)

ข้อสอบ VLSM ของวิชานี้ให้คิดด้วยเลขฐานสอง เพราะการแบ่งวงคือการขีดเส้นแบ่งระหว่างบิต ถ้ามองเป็นบิตได้ ทุกขั้นที่เหลือจะเป็นแค่การนับบิต

บิตซ้ายบอกวง บิตขวาบอกเครื่องNetwork part / Host part

IP หนึ่งตัวแบ่งเป็นสองส่วน: [[netpart]] ทางซ้ายบอกว่าเครื่องอยู่วงไหน และ [[hostpart]] ทางขวาบอกว่าเป็นเครื่องไหนในวงนั้น ตัวเลข [[prefix]] หลังเครื่องหมาย / คือจุดที่ขีดเส้นแบ่ง

เช่น 192.168.1.37/26 แปลว่า 26 บิตแรกเป็นส่วน network เหลือ 32 − 26 = 6 บิตเป็นส่วน host ลองเลื่อน prefix ดูว่าเส้นแบ่งขยับแล้วอะไรเปลี่ยนบ้าง

บิตฝั่ง host มี h ตัว แต่ละตัวเป็น 0 หรือ 1 ได้ จึงมีรูปแบบทั้งหมด 2h แบบ นั่นคือจำนวน IP ในวง ([[block]]) แต่มีสองตัวที่แจกให้เครื่องไม่ได้ คือตัวที่บิต host เป็น 0 หมด ([[netaddr]]) กับตัวที่เป็น 1 หมด ([[bcast]])

ดู class ก่อน แล้วหาว่าต้องเริ่มที่บิตไหนClass + given prefix = where you start

[[cls|Class]] ของ IP ดูจากเลข octet แรก และแต่ละ class มี [[defprefix]] ติดตัวมา ส่วนนั้นเราห้ามแตะ ถ้าโจทย์ให้ prefix ยาวกว่าค่าเริ่มต้น แปลว่าก้อนนี้ถูกแบ่งมาแล้วรอบหนึ่ง บิตที่เกินมาก็ห้ามแตะเหมือนกัน

บิตที่เราใช้แบ่งได้จริงคือบิตที่อยู่ หลัง prefix ที่โจทย์ให้ เท่านั้น จุดนี้คือที่ที่หลายคนพลาด ถ้าก้อนเป็น class B อย่าง 172.16.0.0/20 บิตว่างเริ่มตั้งแต่ octet ที่ 3 ไม่ใช่ octet ที่ 4 ถ้าไปคิดแค่ octet สุดท้ายจะได้วงผิดทั้งหมด

ยืมบิต 1 ตัว วงแตกเป็น 2Borrowing bits = subnetting (FLSM)

การแบ่งวงคือการ [[borrow]] จากฝั่ง host มาต่อท้ายฝั่ง network ยืม s บิตจะได้ 2s วงย่อย และแต่ละวงเล็กลงครึ่งหนึ่งทุกครั้งที่ยืมเพิ่ม

ถ้าทุกวงยืมบิตเท่ากัน ทุกวงก็ขนาดเท่ากัน แบบนี้เรียกว่า [[flsm]] ลองเลื่อนจำนวนบิตที่ยืมดู บิตที่ยืมจะไล่เป็นเลขฐานสอง 000, 001, 010, ... ไปเรื่อยๆ แต่ละเลขคือชื่อวงหนึ่งวง

หาต้นวง ท้ายวง และช่วงที่แจกได้Network, broadcast, usable range

วงทุกวงเริ่มที่ผลคูณของ [[block]] ตัวแรกของวงคือ [[netaddr]] (บิต host เป็น 0 หมด) ตัวสุดท้ายคือ [[bcast]] (บิต host เป็น 1 หมด) ที่อยู่ระหว่างกลางคือ [[range]]

ลองลาก IP ไปตามแถบ แล้วดูว่ามันตกอยู่ในวงไหน ถ้าเปลี่ยน prefix ขนาดวงจะเปลี่ยน แต่วิธีคิดเหมือนเดิมทุกครั้ง

VLSM: แผนกใหญ่ก่อน แล้วแบ่งที่เหลือต่อVariable Length Subnet Mask

[[vlsm]] คือการให้แต่ละแผนกได้วงขนาดไม่เท่ากัน โดยใช้วิธีเดิมทั้งหมด แค่ทำทีละแผนก เริ่มจากแผนกที่ต้องการเครื่องมากที่สุด แล้วเอาวงที่ยังว่างมาแบ่งต่อให้แผนกถัดไป

ขั้นตอนต่อแผนกมีแค่นี้:

  1. หา n ที่น้อยที่สุดที่ 2n − 2 ≥ [[need|จำนวนเครื่อง]] (n คือจำนวน host bit)
  2. prefix ใหม่ = 32 − n
  3. วางวงนั้นที่ IP ว่างตัวแรก แล้วหา network, ช่วงที่ใช้ได้ และ broadcast
  4. วงถัดไปเริ่มที่ broadcast + 1

ด้านล่างคือตัวอย่างในชีท 3.2 ทั้งข้อ ก้อน 172.16.0.0/20 ต้องแบ่งให้ 500 hosts 2 วง, 200 hosts 3 วง, 100 hosts 2 วง, 50 hosts 4 วง และ 2 hosts 4 วง ลากแถบด้านล่างเพื่อดูทีละแผนก แถบที่อยู่จะซูมเข้าไปหาวงที่กำลังแบ่ง
