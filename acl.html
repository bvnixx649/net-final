Firewall & ACL

ข้อสอบจะให้รูปเครือข่ายที่มี router, LAN และ server แล้วถามว่า "ถ้าจะบล็อก traffic นี้ ต้องเขียนคำสั่งอะไร" เราต้องเขียนบรรทัด [[acl|ACL]] ให้ถูก แล้วบอกว่าต้องเอาไปใส่ที่ [[iface|interface]] ไหน ทิศ in หรือ out อีกข้อที่จะถามคือ [[firewall]] มีกี่ประเภท แต่ละแบบกันการโจมตีแบบไหนได้

Firewall แต่ละแบบดูลึกไม่เท่ากันPacket filtering, Stateful, Proxy, Hybrid, Personal

[[firewall|Firewall]] คือตัวคัดกรองที่ตัดสินว่า packet ไหนผ่าน packet ไหนทิ้ง ทุกแบบทำงานเหมือนกันตรงนี้ ที่ต่างกันคือมองเห็นข้อมูลได้ลึกแค่ไหน ยิ่งดูลึกยิ่งจับการโจมตีได้มาก แต่ยิ่งช้าและแพง

[[pf]] อ่านแค่ [[header]] ของทีละ packet [[stateful]] จำเพิ่มว่าการเชื่อมต่อไหนเปิดอยู่ใน [[statetable]] [[proxy]] เปิดอ่านเนื้อหาในชั้น Application และคุยแทนเครื่องข้างใน [[hybrid]] รวมทุกอย่างไว้ด้วยกัน ส่วน [[personal]] อยู่บนคอมพิวเตอร์เครื่องเดียว

เลือกประเภท แล้วดูว่า packet ปกติและการโจมตีแต่ละแบบที่ยิงเข้ามาจาก Internet ผ่านไปได้หรือไม่ โจทย์สมมติว่ากฎตั้งไว้ให้คนนอกเข้าได้แค่เว็บ (port 80) ของ server

ข้อสังเกตที่ออกสอบได้: [[sniff|Sniffing]] ไม่มี firewall ไหนกันได้ เพราะผู้โจมตีแค่แอบอ่านระหว่างทาง ต้องใช้การเข้ารหัส ส่วน [[spoof|IP spoofing]] เป็นจุดอ่อนที่สไลด์เขียนไว้ตรงๆ ของ packet filtering

ในองค์กรจริง firewall มักวางคั่นโซน: [[untrusted]] (Internet), [[dmz|DMZ]] ที่วาง server ซึ่งคนนอกต้องเข้า เช่น web และ mail, และ [[trusted]] คือ LAN ภายใน

ACL คือรายการกฎ ตรวจจากบนลงล่างTop-down, first match wins, implicit deny

[[acl|ACL]] คือรายการ [[statement]] ที่ router เก็บไว้ packet หนึ่งตัวถูกเทียบทีละบรรทัดจากบนลงล่าง บรรทัดแรกที่ตรงเป็นตัวตัดสิน ([[permit]] หรือ [[deny]]) ถ้าไม่ตรงสักบรรทัดจะโดน [[implicit]] ที่ซ่อนอยู่ท้ายสุด

นี่คือ packet filtering firewall ที่ทำบน router ตัวอย่างด้านล่างเป็น ACL ที่ตั้งใจห้ามเครื่อง 172.16.3.2 แต่ให้เครื่องอื่นใน LAN 172.16.3.0 ผ่าน เลือก packet แล้วดูว่ามันเดินลงไปหยุดที่บรรทัดไหน จากนั้นลองสลับลำดับ หรือเพิ่ม permit any ท้ายรายการ

สามกฎที่ต้องจำจากภาพนี้: [[firstmatch]], บรรทัดเจาะจงไว้บน บรรทัดกว้างไว้ล่าง, และถ้าโจทย์อยากให้อย่างอื่นผ่านตามปกติ ต้องปิดท้ายด้วย permit เอง

Wildcard mask: 0 ต้องตรง 1 ไม่สนใจWildcard mask = inverse of the subnet mask

ใน ACL ทุก address มี [[wildcard]] ตามหลัง router อ่านทีละบิต: บิตที่ wildcard เป็น 0 ต้องตรงกับ address ที่เขียน บิตที่เป็น 1 จะเป็นอะไรก็ได้

wildcard คือ [[smask|subnet mask]] กลับด้าน หาได้จาก 255 ลบทีละ octet วง /24 ใช้ 0.0.0.255 วง /27 ใช้ 0.0.0.31 ถ้าเป็นเครื่องเดียวใช้ 0.0.0.0 หรือเขียนคำว่า [[hostkw|host]] นำหน้า ถ้าทุก address ใช้ [[anykw|any]]

ในทางปฏิบัติไม่ต้องแปลงฐานสองทั้ง 32 บิต: octet ที่ wildcard เป็น 0 ให้เทียบเลขฐานสิบตรงๆ octet ที่เป็น 255 ข้ามไปเลย มีแค่ octet ที่อยู่ระหว่างกลางที่ต้องดูทีละบิต แตะ octet ไหนก็ได้เพื่อดูบิตข้างใน

Standard หรือ Extended และวางที่ไหนStandard near destination, extended near source

[[standard]] ดูได้แค่ IP ต้นทาง [[extended]] ดูได้ทั้งต้นทาง ปลายทาง protocol และ port เลขของ ACL บอก router ว่าเป็นชนิดไหน และชนิดเป็นตัวกำหนดว่าต้องวางใกล้ปลายทางหรือใกล้ต้นทาง

ทิศ [[inbound|in]] กับ [[outbound|out]] มองจากตัว router เสมอ packet ที่กำลังเข้า router ทางขาไหนคือ in ของขานั้น packet ที่กำลังออกคือ out ACL ที่วางผิดทิศจะไม่เจอ packet ที่ตั้งใจจะบล็อกเลย

โจทย์: ห้าม PC 172.16.3.2 เข้าถึง Server 172.16.4.13 แต่เครื่องนี้ยังต้องออก Internet ได้ และเครื่องอื่นต้องใช้ server ได้ปกติ เลือกชนิด ACL แล้วเลือกขาและทิศที่จะวาง ดูว่ามีอะไรถูกบล็อกเกินโดยไม่ตั้งใจบ้าง

สไลด์ p.41 apply ACL 120 แบบ in ที่ f0/0 ทั้งที่ทุกบรรทัดเขียนถึง packet ที่วิ่งไปหา server ซึ่งออกจาก router ทาง f0/0 ตามหลักจึงต้องเป็น out (ชีทแล็บ 7 ใช้ out ที่ f0/0 ทุกตัวอย่าง) ถ้าข้อสอบเอารูปนี้มาถาม ให้เขียนตามหลักและอธิบายทิศสั้นๆ

ถ้าโจทย์พูดถึงการ telnet เข้าตัว router เอง ไม่ได้ผ่าน router ไปที่อื่น ให้ใช้ standard ACL กับ [[vty|line vty และ access-class]] แทนการผูกที่ interface

บริการไหนใช้ port อะไรWell-known ports

ถ้าโจทย์พูดถึงบริการ เช่น Telnet, เว็บ, FTP หรือ ping ต้องใช้ extended ACL ระบุ [[proto|protocol]] และ [[port]] ปลายทางด้วย [[eq|eq]] หลังปลายทาง ยกเว้น ping ที่ใช้ [[icmp|ICMP]] ซึ่งไม่มี port

แตะแต่ละบริการเพื่อดูว่าในคำสั่งต้องเขียนส่วนนี้อย่างไร ตาราง port ในชีทแล็บ 7 มี 20, 21, 23, 80 และ 161 ที่เหลือเป็น port มาตรฐานที่ควรรู้

ทุกข้อทำตามลำดับเดิม: หาต้นทางกับปลายทาง, ตัดสินว่า standard หรือ extended, เขียนบรรทัดจากเจาะจงไปกว้าง, ปิดท้ายด้วย permit ถ้าต้องให้อย่างอื่นผ่าน, แล้วเลือกขาและทิศ

แตะเครื่องในรูปเพื่อเลือกต้นทาง แตะอีกครั้งเพื่อเลือกปลายทาง จากนั้นเลือกบริการและสิ่งที่ต้องการ คำสั่งทั้งชุดจะประกอบให้ทันที แตะคำไหนในคำสั่งเพื่อดูว่าคำนั้นมาจากไหน
