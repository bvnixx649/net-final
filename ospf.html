OSPF

OSPF ไม่มีโจทย์คำนวณ ข้อสอบจะให้อธิบายว่า [[ospf]] ทำงานเป็นขั้นตอนอย่างไรตั้งแต่เปิดเครื่องจนได้ routing table, มีข้อดีอะไร และต่างจาก RIP กับ EIGRP ตรงไหน

ทุกตัวถือแผนที่ฉบับเดียวกันLink state vs distance vector

OSPF เป็น [[ls|link state]]: router ทุกตัวรู้ทุกลิงก์และ cost ของมัน เก็บไว้ใน [[lsdb]] ที่เหมือนกันทุกตัว แล้วแต่ละตัวคำนวณเส้นทางเองด้วย [[spf]] ต่างจาก [[dv|distance vector]] ที่รู้แค่สิ่งที่เพื่อนบ้านบอกต่อมา

สลับดูว่า R1 "เห็น" อะไรในสองแบบ แบบ distance vector R1 ได้แต่ตัวเลขที่เพื่อนบ้านบอกมา ไม่รู้ว่าข้างหลังเพื่อนบ้านหน้าตาเป็นอย่างไร

ขั้นตอนการทำงานของ OSPFLink-state operation

OSPF ทำงานห้าขั้นตามลำดับ: ส่ง [[hello|Hello]] หาเพื่อนบ้าน, แลก [[lsa|LSA]], สร้าง [[lsdb|LSDB]], รัน [[spf|SPF]] แล้วใส่เส้นทางที่ดีที่สุดลง [[rtbl|routing table]] หลังจากนั้นจะส่งข้อมูลใหม่เฉพาะตอนที่ลิงก์เปลี่ยน

  1. Hello: ส่ง Hello แบบ multicast 224.0.0.5 ทุก 10 วินาที (dead interval 40 วินาที) เพื่อหาเพื่อนบ้านและสร้าง [[adj|adjacency]] เก็บใน [[nbrtbl|neighbor table]]
  2. แลก LSA: router ส่ง [[lsa|LSA]] บอกสถานะและ cost ของลิงก์ที่ต่อกับตัวเอง แล้ว flood ต่อไปทั่วทั้ง area
  3. สร้าง LSDB: รวม LSA ทั้งหมดเป็น topology table ทุกตัวใน area ได้แผนที่เหมือนกัน
  4. รัน SPF: แต่ละตัวรัน Dijkstra โดยตั้งตัวเองเป็นราก ได้ SPF tree
  5. Routing table: ใส่เส้นทางที่ cost รวมต่ำที่สุดจาก SPF tree ลง routing table (AD 110)

ลากแถบเพื่อดูแต่ละขั้นบนเครือข่ายจริงจากสไลด์ ขั้นสุดท้ายคือสิ่งที่เกิดหลังจากนั้น เมื่อมีลิงก์ขาด

เพื่อนบ้านคุยกันจนฐานข้อมูลตรงกันOperational states: Down → Full

ก่อนจะแลกแผนที่กันได้ router สองตัวต้องไล่ผ่าน [[states|7 สถานะ]]: Down, Init, Two-Way เพื่อสร้าง adjacency แล้ว ExStart, Exchange, Loading จนถึง Full ซึ่งแปลว่าฐานข้อมูลของทั้งคู่ตรงกันแล้ว

นี่คือตัวอย่างจากสไลด์: R1 (router ID 172.16.5.1) กับ R2 (172.16.5.2) ต่ออยู่บน Ethernet วงเดียวกัน ลากแถบเพื่อดูว่าแต่ละสถานะส่งอะไรหากัน

DR กับ BDR บนวง EthernetDesignated Router / Backup DR

ถ้ามีหลาย router ต่อ switch ตัวเดียวกัน ทุกคู่จะต้องสร้าง adjacency กันเอง จำนวนพุ่งขึ้นเป็น n(n−1)/2 OSPF จึงเลือก [[dr|DR]] เป็นตัวแทน และ [[bdr|BDR]] เป็นตัวสำรอง ให้ DR เป็นตัวเดียวที่ส่ง LSA ของวงนั้น

การเลือก: priority สูงสุดชนะ ถ้าเท่ากันดู [[rid|router ID]] สูงสุด ลองเพิ่มจำนวน router แล้วเทียบสองแบบ

แบ่งเป็น area เพื่อให้ขยายได้Single-area vs multiarea, Area 0

เครือข่ายเล็กใช้ [[area]] เดียว เครือข่ายใหญ่แบ่งหลาย area เป็นลำดับชั้น โดยทุก area ต้องต่อกับ [[area0|Area 0]] (backbone) ทำให้ LSDB ของแต่ละ area เล็กลงและคำนวณเร็วขึ้น

router ที่อยู่ระหว่าง area เรียกว่า [[abr|ABR]] ส่วน router ที่ต่อออกไปนอกองค์กร (เช่น ISP) เรียกว่า [[asbr|ASBR]] แตะแต่ละตัวในรูป

Cost คิดจาก bandwidthCost = reference bandwidth / interface bandwidth

[[cost]] ของ interface คือ reference bandwidth หารด้วย bandwidth ของ interface (ปัดเศษทิ้ง ต่ำสุดคือ 1) ลิงก์ยิ่งเร็ว cost ยิ่งต่ำ cost ของเส้นทางคือผลรวม cost ของ interface ขาออกตลอดทาง

ค่าเริ่มต้นของ [[refbw|reference bandwidth]] คือ 100 Mbps ลองเลือก interface กับ reference ดู จะเห็นปัญหาว่าลิงก์ 100 Mbps ขึ้นไปได้ cost 1 เท่ากันหมด

SPF ในสไลด์ ทีละขั้นDijkstra from R1

[[spf|SPF]] เริ่มจากตัวเองที่ cost 0 แล้วยืนยัน router ที่ cost รวมต่ำที่สุดทีละตัว พร้อมอัปเดต cost ของเพื่อนบ้านของตัวที่เพิ่งยืนยัน ทำซ้ำจนครบทุกตัว

ข้อสอบไม่ได้ให้คำนวณส่วนนี้ แต่ดูไว้จะเข้าใจว่าขั้น "รัน SPF" ทำอะไร ตัวเลขตรงกับตาราง routing ของ R1 ในสไลด์ (LAN ทุกวง cost 2)

OSPF ต่างจาก RIP และ EIGRP อย่างไรBenefits and differences

OSPF เด่นที่ classless, converge เร็ว, ขยายได้ด้วย area, ปลอดภัย (มี authentication) และส่ง update เฉพาะตอนเปลี่ยน แลกมาด้วยการใช้ CPU และ memory มากกว่า และตั้งค่าซับซ้อนกว่า
